## Featured Projects

<details>
<summary><strong>SigmaGPT — AI-Powered Multi-User Chat Platform</strong></summary>

<br/>

An enterprise-grade, AI-powered chat platform enabling intelligent multi-turn conversations with persistent memory — built on the Groq LLM API and a full MERN backend architecture.

| Attribute | Details |
|:---|:---|
| **Stack** | JavaScript, Node.js, Express.js, MongoDB Atlas, Groq LLM API |
| **Scale** | Multi-user concurrent sessions with isolated conversation state |
| **Performance** | Real-time AI response streaming; optimized message threading |
| **Security** | Environment-based secrets management; structured API error handling |
| **Impact** | Production-ready AI chat platform with persistent history & code rendering |
| **Repository** | [github.com/Kiranthr/SigmaGPT](https://github.com/Kiranthr) |

**Engineering Highlights:**

- Integrated the **Groq LLM API** to power real-time AI responses with multi-turn context retention, storing full conversation history in **MongoDB Atlas** for session persistence across users.
- Architected a robust **Node.js + Express.js** backend managing conversation state, session tokens, and concurrent message threading — designed for reliability under parallel user load.
- Built a responsive chat interface with **Markdown rendering and syntax highlighting** for AI-generated code blocks, optimizing developer readability and UX clarity.
- Applied **production-grade engineering practices**: environment-based secrets management, centralized error handling, and structured API response formatting throughout the entire backend layer.

</details>

<details>
<summary><strong>Wanderlust — Full-Stack Rental Marketplace</strong></summary>

<br/>

A full-stack property rental marketplace inspired by Airbnb — engineered with a production-quality REST API layer, normalized database schema, JWT-based authentication, and a clean MVC architecture.

| Attribute | Details |
|:---|:---|
| **Stack** | MongoDB, Express.js, Node.js, HTML5, CSS3, JavaScript |
| **Scale** | Multi-entity relational schema — users, listings, reservations |
| **Performance** | Indexed MongoDB queries for optimized property search & lookup |
| **Security** | JWT-based session auth; role-based access control; env-based config |
| **Impact** | End-to-end rental platform covering listings, bookings, and user auth |
| **Repository** | [github.com/Kiranthr/Wanderlust](https://github.com/Kiranthr) |

**Engineering Highlights:**

- Designed a **RESTful API layer** with Node.js and Express.js handling authentication flows, property listings CRUD, and booking workflows — secured with **JWT sessions and role-based access control**.
- Modeled a **normalized MongoDB schema** for users, listings, and reservations with indexed queries, significantly reducing lookup latency for property search operations at scale.
- Enforced strict **MVC architecture**, cleanly separating business logic from routing — improving maintainability and enabling feature growth without architectural degradation.
- Implemented comprehensive **security and reliability measures**: input validation, centralized error handling, environment-based configuration, and secure session management across all API routes.

</details>
